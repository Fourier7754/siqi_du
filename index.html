Research Interests

  • Agent Harness
    How to build efficient, reliable intelligent agent systems—from orchestration to deployment.
  • Agent Computation Graph
    Using computation graphs to manage memory efficiently and reduce inference cost during agent reasoning.
  • Implicit Representation Learning
    Mapping physical-world properties into implicit representations that neural networks can learn, query, and compose.
  • Efficient Representation Learning
    Lightweight representation learning for on-device and edge deployment with minimal latency and energy use.
